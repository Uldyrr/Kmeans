# Kmeans
This is a simple K-means algorithm implementation which you can use to quickly retrieve
the centroids of K clusters for a given input array of 2D points. Go to the main entry point and update "K" and "pointsValues" to whatever you want.

## How to run
Run "make", followed by "make run". \
If you need to debug, run "make debug" \
To clean, run "make clean"
